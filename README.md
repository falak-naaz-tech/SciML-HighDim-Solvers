# SciML-HighDim-Solvers
### Physics-Informed Neural Networks (PINNs) & Machine Learning for High-Dimensional Differential Equations

This repository houses computational research focused on bypassing the "curse of dimensionality" in physical and biological systems using **Scientific Machine Learning (SciML)** frameworks. 

Traditional numerical techniques (like Finite Element and Finite Difference Methods) scale exponentially as dimensions increase. This project explores neural network architectures capable of solving high-dimensional partial differential equations (PDEs) and stochastic systems by embedding physical and biological laws directly into the loss functions.

## 🔬 Core Focus Areas
* **High-Dimensional Systems:** Evaluating computational scalability across multi-variable biological networks.
* **Physics-Informed Architectures:** Implementing PINNs, Deep BSDE solvers, and Operator Learning methods.
* **Biological Modeling:** Application toward cell dynamics, fluid transport, and metabolic system pathways.

## 🛠️ Tech Stack & Prerequisites
* **Language:** Python 3.x
* **Deep Learning Framework:** PyTorch / JAX
* **SciML Toolkit:** DeepXDE / Custom Neural ODE implementations
